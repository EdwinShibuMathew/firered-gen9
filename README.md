# FireRed Gen 9

This is an orchestration and patch project for a binary-expanded Pokémon FireRed build. It is not a `pret/pokefirered` decompilation. A matching vanilla FireRed ROM is built locally from source, then passed through pinned DPE Gen 9 and CFRU Expansion builds.

Complete ROMs, saves, BIOS files, emulator states, and unlicensed standalone assets must never be committed or distributed. The eventual distributable is a legal patch plus source changes, build scripts, locks, documentation, and credits.

Development is gated by milestones. M0–M2 are complete. M3's reproducible offline-evolution source gates pass and the corrected candidate boots, with controlled evolution/save tests deferred to owner-led QA. M4's automated availability gate is complete at 1,025/1,025 through current wild/scripted acquisitions, evolution closure, and postgame Sevii reserves. M5's form registry and existing permanent item handlers are audited; dedicated field routes, repeatable quests, and the evolution encyclopedia remain. M6's Contrary Charizard starter data and Oak-gift port are implemented; owner-led battle/save QA remains. M7's DexNav foundation is present but migration groups remain optional work. M8's release hygiene and boundary test matrix are documented; legal patch generation and manual execution remain.
